FRIEND FINDER - SOURCE CODE

Files:
- index.html: page structure
- style.css: responsive layout, colours and graph styling
- script.js: graph data structure and interactive features

HOW TO RUN:
1. Extract the ZIP file.
2. Open the friend_finder_source folder.
3. Double-click index.html, or open it with Chrome/Edge.
4. Click "Try an example" to load demo users.

FEATURES:
- Add users and undirected friendship connections
- Adjacency-list display
- Mutual friends
- Shortest path using BFS
- Friends-of-friends suggestions
- BFS and DFS traversal
- Warm and white themes
- Demo data and reset

NOTE:
This is a recreated, self-contained browser implementation based on the visible features
of the supplied website. It is not the original site's private source code and it does
not call your C++ program. The graph algorithms run in JavaScript in the browser.
