THE DATA STRUCTURE BEHIND THE APP

How it works

◉

A network is a graph

People are represented as vertices (dots), and friendships are edges (lines). Since friendship is mutual, this is an undirected graph.

↗

Nearest first (BFS)

Breadth-First Search explores nearby friends first. It finds the shortest path in an unweighted network.

⌁

Go deep first (DFS)

Depth-First Search follows one connection as far as possible before backtracking to explore another.

⟷

Common friends

Compare two friend lists and keep the names that appear in both. Friends-of-friends can become suggestions.
